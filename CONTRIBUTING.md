# Contributing to 1ps0.github.io

Thank you for considering contributing to this project! Here's how you can help improve the site.

## Ways to Contribute

- **Bug fixes**: If you find an issue with the terminal functionality or website
- **Terminal improvements**: Enhancing existing commands or adding new ones
- **Test coverage**: Adding additional test cases for terminal functionality
- **Documentation**: Improving explanations or examples

## Development Process

1. **Fork the repository** to your GitHub account
2. **Create a feature branch** (`git checkout -b feature/amazing-feature`)
3. **Make your changes**
4. **Test your changes** using the test framework
5. **Commit your changes** (`git commit -m 'Add some amazing feature'`)
6. **Push to the branch** (`git push origin feature/amazing-feature`)
7. **Open a Pull Request**

## Testing Guidelines

When making changes, especially to the terminal functionality:

1. Run the existing test suite at `/tests/terminal-test.html`
2. Add new tests for any new functionality you implement
3. Make sure all tests pass before submitting your PR

## Code Style Guidelines

- Keep the terminal interface consistent with Unix/Linux-like behavior
- Maintain both help systems (`help` command and `--help` flag)
- Use clear, descriptive comments for complex logic
- Follow existing patterns for command implementation

## Documentation

If you add new features, please update the documentation:

- Add entries to the general help command output
- Create specific help text for any new commands
- Update README.md if necessary

## Pull Request Process

1. Ensure your code passes all tests
2. Update documentation if needed
3. Reference any relevant issues in your PR description
4. The PR will be reviewed by maintainers
5. Make any requested changes
6. Once approved, your PR will be merged

## Questions?

If you have questions about contributing, feel free to open an issue for discussion.

Thank you for helping improve this project!
